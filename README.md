# Polski na tablicy

Interaktywne materiały do zajęć z języka polskiego online (zasady gramatyczne, fiszki, quizy, luki, dopasowywanie, rozsypanki, scenki), ułożone według spisu treści podręcznika „Polski krok po kroku 1”. Wszystkie ćwiczenia i dialogi są autorskie.

- `index.html` – silnik strony
- `spis.js` – spis treści i lista gotowych rozdziałów (`GOTOWE`)
- `gramatyka.js` – dział „Gramatyka”: zasady z rozdziałów ułożone tematami oraz tabele „Siedem przypadków”
- `rozdzialy/rNN.js` – treść rozdziałów
